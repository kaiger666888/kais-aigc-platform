# Task Spec: 时间轴播放器折叠/展开控制

## 背景
工作目录：/data/workspace/kais-aigc-platform
分支：feat/cinema-knowledge-base
文件：`packages/infinite-canvas/src/components/StoryboardTimeline.tsx`

## 需求
时间轴左侧的播放视频区域需要支持主动折叠/展开：
- **展开时**（默认）：显示播放器区域，点击分镜自动播放视频（当前行为）
- **折叠时**：隐藏播放器区域，分镜列表占满全部宽度，点击分镜不自动播放（只选中高亮）

## 当前代码分析

### 播放器区域（L2349-2354）
```tsx
<div style={{ flex: 1, display: 'flex', flexDirection: 'row', minWidth: 0 }}>
  {/* 左：播放器列（无视频时常驻占位） */}
  {activeVideo ? player : <PlayerPlaceholder fixedWidth={playerFixedWidth} />}
  {/* 右：分镜列表 */}
  {shotList}
</div>
```

### 点击分镜逻辑（L2146-2152）
```tsx
const selectShot = (shot: StoryboardShot) => {
  const rfNode = nodes.find((n) => n.id === shot.node.id)

  }
}
```

### VideoPlayer 组件有 onClose（L2235）
```tsx
onClose={() => setActiveVideo(null)}
```

## 修改方案

### 1. 新增 playerCollapsed 状态
在组件状态区（约 L1883 附近 `activeVideo` 声明处）新增：
```tsx
const [playerCollapsed, setPlayerCollapsed] = useState(false)
```

### 2. 修改播放器区域渲染（L2349-2354）
```tsx
<div style={{ flex: 1, display: 'flex', flexDirection: 'row', minWidth: 0 }}>
  {/* 左：播放器列 — 可折叠 */}
  {!playerCollapsed && (activeVideo ? player : <PlayerPlaceholder fixedWidth={playerFixedWidth} />)}
  {/* 右：分镜列表（折叠时占满宽度） */}
  {shotList}
</div>
```

### 3. 新增折叠/展开切换按钮
在播放器列和分镜列表之间，放一个**竖向窄条按钮**（宽 28px），用于切换折叠/展开。

折叠态：
- 显示一个竖向窄条（28px 宽，全高），背景 `theme.bg.panel`
- 中央有一个 `▶` 图标（表示展开）+ 竖向文字「播放器」
- hover 高亮

展开态：
- **不需要显示这个切换条**（因为播放器已有占位区）
- 改为在**统计栏右侧**加一个折叠按钮 `◀ 收起播放器`

更好的方案（推荐）：**在统计栏中加一个切换按钮**

在统计栏（L2272-2343）的最右侧（`💡 单击播放视频` 提示文字的位置），替换为：
```tsx
{/* 播放器折叠/展开切换 */}
<button
  onClick={() => {
    setPlayerCollapsed(v => !v)
    if (activeVideo) setActiveVideo(null) // 折叠时清除视频
  }}
  style={{
    background: 'none', border: `1px solid ${theme.border.default}`,
    borderRadius: 4, cursor: 'pointer',
    padding: '3px 10px', fontSize: 11,
    color: playerCollapsed ? theme.text.tertiary : theme.text.primary,
    display: 'flex', alignItems: 'center', gap: 4,
    whiteSpace: 'nowrap',
  }}
  title={playerCollapsed ? '展开播放器' : '收起播放器'}
>
  {playerCollapsed ? '▶ 展开播放器' : '◀ 收起播放器'}
</button>
```

### 4. 修改 selectShot 逻辑（L2146-2152）
```tsx
const selectShot = (shot: StoryboardShot) => {
  const rfNode = nodes.find((n) => n.id === shot.node.id)
  if (rfNode) setSelectedNode(rfNode)
  // 仅播放器展开时才自动播放
  if (!playerCollapsed && shot.videoUrl) {
    setActiveVideo({ shotId: shot.shotId, videoUrl: shot.videoUrl, durationS: shot.durationS })
  }
}
```

### 5. 折叠时清除活跃视频
在折叠按钮 onClick 中（步骤3已包含）：`if (activeVideo) setActiveVideo(null)`

### 6. 更新提示文字
统计栏的 `💡 单击播放视频，双击查看详情` 提示应随状态变化：
- 展开时：`💡 单击播放视频，双击查看详情`
- 折叠时：`💡 单击选中分镜，双击查看详情`（不提"播放视频"）
