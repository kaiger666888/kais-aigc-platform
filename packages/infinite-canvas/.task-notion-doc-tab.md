# Task: 无限画布新增「创作文档」Tab — Notion 设计文档嵌入与管理

## 目标

在无限画布资产管理中心（AssetManager）新增第 4 个 Tab **「创作文档」**，
让 Kai 可以在画布中直接查阅 Notion 创作设计文档，无需跳出到 Notion。

## 背景

Kai 的项目「她从深渊归来」(ID: 1785508691757) 有完整的 Notion 设计文档：
- 主页面 ID: `3ae11082-af8e-80ad-8af7-eada9c3416f0`

## UI 设计规范

- 文档树侧栏：固定宽度 240px，与 AssetLibrary 左栏风格一致

## 技术注意事项

1. Notion API 限制 ~3 req/s，递归读取时加 `await sleep(300)` 间隔
2. 递归深度限制 3 层（防止超大页面如"剧情"拉取太慢）
3. 表格 block 需要 `has_children: true` 时单独 query 子 blocks
4. Token 从 `process.env.NOTION_TOKEN` 读取（.env 中已配置）
5. API 请求头：`Authorization: Bearer ${token}`, `Notion-Version: 2022-06-28`
6. 前端用 `useEffect` + `useState` 管理 loading/error/data 状态
7. 文档内容可能很长 → 内容区要 `overflow-y: auto` + 虚拟滚动暂不需要
