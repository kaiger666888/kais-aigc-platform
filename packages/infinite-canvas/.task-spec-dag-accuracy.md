### 问题 A1: scene-images 永远 pending
**根因**：DAG match `{ phaseIndex: 7, stage: 'global', assetType: 'scene' }`，但 44 个 scene_image 节点全部在 `phase_index=0`（不是 7），且 `assetType='scene_image'`（不是 `'scene'`）。

**数据**：
```

phase_index=7 → 0 个 scene asset 节点
```

**修复**：修改 match 规则，兼容 phase_index=0 的 scene_image 节点：
```typescript

  expectedCount: 'dynamic' },
```

注意：`idPrefix: 'a-scene_refs-'` 可以精确匹配场景图节点，不会误匹配 PI=0 的 keyframe。

## B. DAG match 规则修正方案

### model.ts 修改

1. **scene-images**：改 match 规则
```typescript
{ id: 'scene-images', label: '场景图', phaseCode: 'P07', phaseIndex: 7, group: 'production',
  match: { phaseIndex: 0, idPrefix: 'a-scene_refs-' },
  expectedCount: 'dynamic' },
```

2. **character-bible** 和 **voice-design**：添加派生完成逻辑

在 `deriveDagModels` 函数中，添加「派生完成」逻辑：

```typescript
// 特殊派生规则：如果下游节点已完成，则上游节点自动标记为 completed
// character-bible: 如果 turnaround-sheets 有成功节点，bible 必然已完成
// voice-design: 如果 voice-clips (P10) 有成功节点，声纹设计必然已完成
function deriveImplicitCompletion(
  defId: string, 
  models: Map<string, DagNodeModel>
): boolean {
  switch (defId) {
    case 'character-bible':
      // 如果 turnaround-sheets 有完成节点，bible 必然完成
      return (models.get('turnaround-sheets')?.completed ?? 0) > 0
    case 'voice-design':
      // 如果 voice-clips (P10) 有完成节点，声纹必然完成
      return (models.get('voice-clips')?.completed ?? 0) > 0
    default:
      return false
  }
}
```

然后在 `deriveDagModels` 中：
```typescript
// 后处理：派生完成检查
for (const m of models) {
  if (m.total === 0 && deriveImplicitCompletion(m.def.id, modelMap)) {
    m.state = 'completed'
    m.present = true
    m.total = 1
    m.completed = 1
  }
}
```
