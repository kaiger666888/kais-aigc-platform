# Task: 画布视口历史导航（前进/后退按钮）

## 目标

在画布左上工具栏添加「后退 ←」「前进 →」按钮，让用户能回溯之前的视口位置。
类似浏览器的后退/前进功能，但针对 React Flow 画布视口（x, y, zoom）。

## 核心逻辑

### 1. 创建 hook: `src/hooks/useViewportHistory.ts`

维护一个视口历史栈（past[] + future[]），当前视口不在栈中。

```
状态:
  past: Viewport[]     // 已经离开的视口
  future: Viewport[]   // 后退后可以前进到的视口

操作:
  push(vp: Viewport)   // 用户移动到新视口时调用：past.push(current); future=[]
  back(): Viewport|null // 后退：future.unshift(current); return past.pop()
  forward(): Viewport|null // 前进：past.push(current); return future.shift()
  canBack: boolean     // past.length > 0
  canForward: boolean  // future.length > 0
```

### 去抖动

用户拖拽画布会触发大量中间状态。只在 `onMoveEnd` 时 push（已经是拖拽结束），但仍需防抖：

- 与上一个 push 的视口距离 < 50px 且 zoom 差 < 0.1 → 不 push（视为同一位置微调）
- 初始加载/程序性 setViewport 时不 push（用一个 `enabledRef` 标记）

### 上限

past 最多 50 条，超出 shift 掉最早的。

## 2. 在 FlowCanvas.tsx 中接入

### 导入

```tsx
import { useViewportHistory } from '../hooks/useViewportHistory'
```

### 在 CanvasInner 中初始化

```tsx
const viewportHistory = useViewportHistory()
```

### 修改 handleMoveEnd

当前：
```tsx
const handleMoveEnd = useCallback(
  (_e: unknown, viewport: { x: number; y: number; zoom: number }) => persistViewport(viewport),
  [persistViewport],
)
```

改为（在 persistViewport 之前加 history push）：
```tsx
const handleMoveEnd = useCallback(
  (_e: unknown, viewport: { x: number; y: number; zoom: number }) => {
    viewportHistory.push(viewport)
    persistViewport(viewport)
  },
  [persistViewport, viewportHistory],
)
```

### 添加后退/前进处理函数

```tsx
const handleViewportBack = useCallback(() => {
  const prev = viewportHistory.back()
  if (prev) {
    reactFlow.setViewport(prev, { duration: 300 })
  }
}, [viewportHistory, reactFlow])

const handleViewportForward = useCallback(() => {
  const next = viewportHistory.forward()
  if (next) {
    reactFlow.setViewport(next, { duration: 300 })
  }
}, [viewportHistory, reactFlow])
```

**重要**：setViewport 会触发 onMoveEnd → push。为避免循环，在 back/forward 时设一个 flag：

```tsx
const skipPushRef = useRef(false)

const handleMoveEnd = useCallback(
  (_e: unknown, viewport: { x: number; y: number; zoom: number }) => {
    if (!skipPushRef.current) {
      viewportHistory.push(viewport)
    }
    skipPushRef.current = false
    persistViewport(viewport)
  },
  [persistViewport, viewportHistory],
)

const handleViewportBack = useCallback(() => {
  const prev = viewportHistory.back()
  if (prev) {
    skipPushRef.current = true
    reactFlow.setViewport(prev, { duration: 300 })
  }
}, [viewportHistory, reactFlow])

const handleViewportForward = useCallback(() => {
  const next = viewportHistory.forward()
  if (next) {
    skipPushRef.current = true
    reactFlow.setViewport(next, { duration: 300 })
  }
}, [viewportHistory, reactFlow])
```

### 在工具栏添加按钮

在 `<Panel position="top-left">` 内，搜索框之前，添加两个按钮：

```tsx
<ToolbarButton onClick={handleViewportBack} disabled={!viewportHistory.canBack}>
  ←
</ToolbarButton>
<ToolbarButton onClick={handleViewportForward} disabled={!viewportHistory.canForward}>
  →
</ToolbarButton>
```

用 `←` 和 `→` Unicode 箭头作为文本即可（与现有 ToolbarButton 风格一致）。

### 初始化视口记录

在首次 fitView 或恢复持久化视口后，需要把初始视口设为历史起点。在 useViewportHistory 内部用 `initializedRef` 处理：首次 push 时不 push 到 past，直接设为 current。

## 5. 注意事项

1. `useViewportHistory` 返回的对象需要稳定引用（用 useRef 存内部状态，useCallback 包方法），否则每次渲染都导致 FlowCanvas 的 useCallback 依赖失效
2. ToolbarButton 组件已有 `disabled` prop 支持
3. `reactFlow.setViewport(vp, { duration: 300 })` 会触发动画过渡，不会触发 onMove 多次（只在动画结束时触发一次 onMoveEnd）
4. 初始视口（页面加载时的 fitView 或持久化恢复）不应记入历史
