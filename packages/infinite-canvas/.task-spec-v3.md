## 问题2：分镜级资产排序错误

### 现状

### 要求
**全部首尾帧移到最下面**。正确顺序应为：
1. 各 shotGroup（S01_B01, S02_B02...）按自然序排序
2. costume_turnaround 🎭 分镜级Turnaround
3. costume_temporal_variant 👔 服化道时段变体
4. 🗣️ 对白 🎙️ （新增，问题1）
5. scene_angle_shot 🎥 场景角度图
6. foley_stem 👣 Foley音轨
7. bgm_track 🎼 BGM音轨
8. midframe 🔀 关键中间帧 → **如果这个不应该在这里，移除它**
9. **全部首尾帧入口** → 移到最下面

### 关于"多了中间帧和首尾帧的部分"
用户说"多了中间帧和首尾帧的部分"。意思是：**分镜级不应该有「全部首尾帧」入口和「中间帧」入口**。

- **全部首尾帧**：这是一个聚合入口，应该只在更上层（比如场景级或独立入口），不应该出现在分镜级
- **中间帧(midframe)**：分镜级下面不应该有中间帧这个类别（中间帧属于帧变体范畴，已被首尾帧变体覆盖）

所以分镜级最终应为：
1. 各 shotGroup（S01_B01, S02_B02...）
2. costume_turnaround 🎭
3. costume_temporal_variant 👔
4. 🗣️ 对白 🎙️ （新增）
5. scene_angle_shot 🎥
6. foley_stem 👣
7. bgm_track 🎼

**移除**：全部首尾帧入口、中间帧入口。

同时修复排序：shotGroup 应该用**自然排序**（S01_B01 < S02_B01 < S10_B01），不要用纯字典序 localeCompare。用 `localeCompare(b.id, undefined, { numeric: true })`。

## 问题3：时间轴对白只显示1条（实际有7条）

### 调查结论

**后端数据正常**：API `/api/canvas/v2/load-v2` POST 返回 7 条 `type='audio'` 节点，全部 `clip_type='dialogue'`，`shot_id` 完整（S01_B04, S02_B02, S02_B03, S03_B02, S03_B03, S04_B03, S05_B01），`filePath` 存在。

**shotKey 匹配正确**：7 条 audio 节点的 shotKey（s1_4, s2_2, s2_3, s3_2, s3_3, s4_3, s5_1）全部命中 storyboard 节点的 shotKey。

**根因定位**：问题在 `extractShots()` 函数的 Pass 4（StoryboardTimeline.tsx L358-388）。

Pass 4 遍历 `graph.nodes`（这是 **V3 migrate 后**的节点列表），检查 `node.kind !== 'asset'` → 如果 V3 migrate 后 audio 节点丢失了或 kind 不对，就会跳过。

**最可能的根因**：V3 migrate 后，audio 节点的 `node.kind` 可能变成了 `'event'` 而不是 `'asset'`（检查 migrate.ts L424-497 的逻辑），或者 migrate 后 audio asset nodes 虽然存在但 `node.modality` 和 `node.stage` 不满足 `node.modality === 'audio' || node.stage === 'voice'` 的条件。

### 修复方案

**关键文件**：`packages/infinite-canvas/src/components/StoryboardTimeline.tsx`

1. 在 Pass 4（L358-388）添加**调试日志**来确认 V3 graph 中 audio 节点的实际 kind/stage/modality
2. **修复匹配逻辑**：不要依赖 V3 migrate 后的 kind/stage/modality（这些可能因为 data.audioType 是中文"人声"而不是英文"voice"导致误判），改用 **rawDataByNodeId** 来判断：
   ```typescript
   // 不再仅靠 node.kind/stage/modality 筛选
   // 改为检查 rawDataByNodeId 中是否有 audio 相关字段
   const raw = rawDataByNodeId?.get(node.id) ?? {}
   const isAudio = raw.clip_type || raw.audio_type || raw.audio_path || 
                   (raw.filePath && /\.(wav|mp3|aac|flac|ogg|m4a)$/.test(raw.filePath))
   if (!isAudio) continue
   ```
3. 这样即使 V3 migrate 把 audio 节点的 stage/modality 设错了，也能通过原始 data 中的字段正确识别

同时确保对白统计（L1972-1973）也修复：
```typescript
const withAudio = shots.filter((s) => s.audioTracks && s.audioTracks.length > 0).length
const audioCount = shots.reduce((sum, s) => sum + (s.audioTracks?.length ?? 0), 0)
```
修复后 audioCount 应该 = 7。
