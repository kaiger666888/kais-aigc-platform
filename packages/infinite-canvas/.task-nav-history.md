# Task: 应用级状态历史导航（全局前进/后退）

## 目标

将之前的视口导航升级为**应用级状态历史**。用户每次产生有意义的导航交互（切换视图、选中节点、打开面板等）都记入历史栈。点击 ← / → 能精确恢复到之前的完整应用状态。

## 核心设计：快照 + 拦截

### 状态快照定义

```typescript
interface NavSnapshot {
  viewMode: 'canvas' | 'timeline' | 'assets'
  assetView: 'library' | 'detail' | 'wardrobe' | 'scenes'
  selectedNodeId: string | null    // 从 selectedNode?.id 提取
  detailNodeId: string | null      // 从 detailNode?.id 提取
  selectedAssetUuid: string | null
  viewport: { x: number; y: number; zoom: number } | null
}
```

### 触发快照记录的交互（拦截点）

| 交互 | 当前代码位置 | 拦截方式 |
|------|-------------|---------|
| 切换视图模式（画布/时间轴/资产） | FlowCanvas ViewModeButton onClick → setViewMode | 包装 setViewMode |
| 点击节点（选中+溯源） | FlowCanvas onNodeClick → setSelectedNode | 包装 onNodeClick |
| 双击节点（打开详情面板） | FlowCanvas onNodeDoubleClick → setDetailNode | 包装 onNodeDoubleClick |
| 点击空白画布（取消选中） | FlowCanvas onPaneClick → setSelectedNode(null)+setDetailNode(null) | 包装 onPaneClick |
| 切换资产子视图 | AssetManager setAssetView | 包装 setAssetView |
| 双击打开资产详情 | AssetLibrary openAssetDetail | 包装 openAssetDetail |
| 关闭资产详情 | AssetManager/AssetLibrary closeAssetDetail | 包装 closeAssetDetail |
| 画布拖动/缩放结束 | FlowCanvas onMoveEnd → 已有 viewportHistory.push | 保留现有 |

## 1. 创建 hook: `src/hooks/useNavHistory.ts`

```typescript
import { useCallback, useMemo, useRef, useState } from 'react'
import { useCanvasStore } from '../store/canvasStore'
import type { Viewport } from '@xyflow/react'

export interface NavSnapshot {
  viewMode: 'canvas' | 'timeline' | 'assets'
  assetView: 'library' | 'detail' | 'wardrobe' | 'scenes'
  selectedNodeId: string | null
  detailNodeId: string | null
  selectedAssetUuid: string | null
  viewport: { x: number; y: number; zoom: number } | null
}

export interface NavHistory {
  /** 用户产生导航交互时调用：拍当前状态快照 push 到历史 */
  push: () => void
  /** 后退到上一个快照，返回它（调用方负责 apply） */
  back: () => NavSnapshot | null
  /** 前进到下一个快照，返回它（调用方负责 apply） */
  forward: () => NavSnapshot | null
  canBack: boolean
  canForward: boolean
}
```

### push 逻辑

1. 读取 canvasStore 当前状态构造快照
2. 与上一个快照比较：如果关键字段完全相同 → 不 push（防重复）
3. past.push(prevSnapshot); future = []
4. 上限 30 条

### back / forward

标准的双栈模型。back 返回应恢复的快照，FlowCanvas 负责 apply（调 store setters + reactFlow.setViewport）。

### 去重

- 连续两次 push 的快照如果只有 viewport 变化但位移 <50px 且 zoom 差 <0.1 → 不 push
- 连续两次 push 的快照如果 viewMode/assetView/selectedNodeId/detailNodeId/selectedAssetUuid 完全相同 → 不 push（viewport 变化单独靠 useViewportHistory 的现有逻辑处理，不在这里重复记录）

**重要**：这个 hook 替代 useViewportHistory。viewport 仍记录在快照中，但 push 的判定仍包含 viewport 变化（在交互触发时拍快照会包含当前 viewport）。

### 返回值稳定

方法用 useCallback（空依赖或 syncFlags），返回值用 useMemo。只有 canBack/canForward 变化才产生新引用。

### 引入新的导航历史

```tsx
import { useNavHistory, type NavSnapshot } from '../hooks/useNavHistory'

// 在 CanvasInner 中
const navHistory = useNavHistory()
const navSkipRef = useRef(false)  // 防止 apply 时触发递归 push
```

### 包装所有交互回调

每个交互在执行原逻辑后调 `navHistory.push()`（除非 navSkipRef 为 true）：

```tsx
// 视图切换
const handleSetViewMode = useCallback((mode) => {
  if (navSkipRef.current) { setViewMode(mode); return }
  navHistory.push()
  setViewMode(mode)
}, [navHistory, setViewMode])

// ViewModeButton 用 handleSetViewMode 替代 setViewMode

// 节点点击
const onNodeClick = useCallback((_event, node) => {
  if (node?.type === 'eventChip') return
  if (!navSkipRef.current) navHistory.push()
  setSelectedNode(node)
  setDetailNode(null)
}, [navHistory, setSelectedNode, setDetailNode])

// 节点双击
const onNodeDoubleClick = useCallback((_event, node) => {
  if (node?.type === 'eventChip') return
  if (!navSkipRef.current) navHistory.push()
  setSelectedNode(node)
  setDetailNode(node)
}, [navHistory, setSelectedNode, setDetailNode])

// 空白点击
const onPaneClick = useCallback(() => {
  setMenuPos(null)
  if (!navSkipRef.current) navHistory.push()
  setSelectedNode(null)
  setDetailNode(null)
  setActiveChip(null)
}, [navHistory, setMenuPos, setSelectedNode, setDetailNode])

// MoveEnd — viewport 变化也 push（保留旧逻辑的 viewport 持久化）
const handleMoveEnd = useCallback((_e, viewport) => {
  if (!navSkipRef.current) navHistory.push()
  persistViewport(viewport)
}, [navHistory, persistViewport])
```

### apply 快照函数

```tsx
const applyNavSnapshot = useCallback((snap: NavSnapshot) => {
  navSkipRef.current = true
  const store = useCanvasStore.getState()
  store.setViewMode(snap.viewMode)
  store.setAssetView(snap.assetView)
  store.setSelectedAssetUuid(snap.selectedAssetUuid)
  // selectedNode / detailNode 需要从 nodes 数组查找
  const nodes = store.nodes
  store.setSelectedNode(snap.selectedNodeId ? nodes.find(n => n.id === snap.selectedNodeId) ?? null : null)
  store.setDetailNode(snap.detailNodeId ? nodes.find(n => n.id === snap.detailNodeId) ?? null : null)
  if (snap.viewport) {
    reactFlow.setViewport(snap.viewport, { duration: 300 })
  }
}, [reactFlow])

const handleNavBack = useCallback(() => {
  const snap = navHistory.back()
  if (snap) applyNavSnapshot(snap)
}, [navHistory, applyNavSnapshot])

const handleNavForward = useCallback(() => {
  const snap = navHistory.forward()
  if (snap) applyNavSnapshot(snap)
}, [navHistory, applyNavSnapshot])
```

### 按钮位置改为顶栏（全局，不在画布内）

把 ← → 按钮从画布内 Panel 移到**顶部导航栏**（顶栏标题"无限画布"右侧），因为它是全局功能不只作用于画布：

```tsx
// 在 topBarStyle 的 div 中，视图模式切换按钮之后加：
<div style={{ display: 'flex', gap: 0, borderRadius: 7, overflow: 'hidden', border: `1px solid ${theme.border.default}`, ... }}>
  <NavArrowButton onClick={handleNavBack} disabled={!navHistory.canBack} title="后退" label="←" />
  <NavArrowButton onClick={handleNavForward} disabled={!navHistory.canForward} title="前进" label="→" />
</div>
```

### 保留 NavArrowButton 组件

保留 NavArrowButton 组件定义（34×32px 圆角组合按钮，18px 粗体箭头），只是改了调用方的 handler 和位置。

## 3. 修改 AssetManager.tsx 和 AssetLibrary.tsx

需要让这些组件的交互也触发 navHistory.push()。

**方案**：在 canvasStore 中加一个 `navPush` 回调字段，FlowCanvas 挂载时注入 navHistory.push，子组件通过 store 调用。

```typescript
// canvasStore.ts 新增
navPushCallback: (() => void) | null
setNavPushCallback: (fn: (() => void) | null) => void
```

FlowCanvas 中：
```tsx
useEffect(() => {
  useCanvasStore.getState().setNavPushCallback(() => navHistory.push())
  return () => useCanvasStore.getState().setNavPushCallback(null)
}, [navHistory])
```

AssetManager.tsx 的 setAssetView 包装：
```tsx
const rawSetAssetView = useCanvasStore((s) => s.setAssetView)
const setAssetView = useCallback((v) => {
  useCanvasStore.getState().navPushCallback?.()
  rawSetAssetView(v)
}, [rawSetAssetView])
```

AssetLibrary.tsx 的 openAssetDetail / closeAssetDetail 包装：
```tsx
const openAssetDetail = useCanvasStore((s) => s.openAssetDetail)
// 双击时：
onDoubleClick={(e) => {
  e.stopPropagation()
  useCanvasStore.getState().navPushCallback?.()
  openAssetDetail(a.uuid)
}}
```
