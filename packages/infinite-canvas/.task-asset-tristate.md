# Task: 资产管理三态模型 + 切换不闪烁

## 需求

### 1. 三态模型（选定 / 待选 / 淘汰）

当前只有两态（isPrimaryView true/false）。增加第三态「淘汰」：

- **选定**：`isPrimaryView=true, state='active'`
- **待选**：`isPrimaryView=false, state='active'`
- **淘汰**：`state='eliminated'`（isPrimaryView 必须为 false）

流转规则：
- 用户在「待选」中点「选定」→ 该资产变选定，**同组旧选定资产自动变淘汰**
- 用户在「选定」中点「取消选定」→ 该资产变待选，**同组淘汰的资产自动恢复为待选**
- 用户在「淘汰」中可手动恢复某资产到待选

### 2. 切换不闪烁

当前问题：每次选定/取消选定后调 `reload()` → assets 数组完全重建 → 列表闪烁 + 滚动跳顶。

修复方案：**乐观更新**——先在前端直接修改 assets 数组，不调 reload()。后端 API 已经同步完成，下次自然刷新时会拿到正确状态。

## 实现步骤

### A. 后端：search 不默认过滤 state

文件：`src/routes/v1/assets-registry/index.ts`

当前 searchSchema 的 `state` 默认值是 `"active"`，导致淘汰的资产查不到。

改为：`state: z.string().optional()`（去掉 `.default("active")`）。

查询逻辑：如果 `s.state` 有值则 filter，否则不过滤（返回所有状态的资产）。

当前代码：
```ts
q = q.where("a.state", s.state);
```
改为：
```ts
if (s.state) q = q.where("a.state", s.state);
```

### B. 后端：updateSchema 允许 eliminated 状态

文件：`src/routes/v1/assets-registry/index.ts`

当前 updateSchema：
```ts
state: z.enum(["active", "archived"]).optional(),
```
改为：
```ts
state: z.enum(["active", "archived", "eliminated"]).optional(),
```

### C. 前端：useRealAssets 不传 state（拉所有状态）

文件：`src/components/assetManager/useRealAssets.ts`

当前不传 state（后端默认 active）。现在后端去掉了默认值，所以前端也不传 state，自然拉到所有状态的资产。

#### D2. tabFiltered 改为三态过滤

#### D3. 乐观更新 helper（替代 reload）

```typescript
/** 乐观更新单条资产的字段，不触发 reload（避免闪烁/跳顶） */
const patchAssetLocal = useCallback((assetId: number, patch: Partial<AssetDetail>) => {
  // 直接操作 useRealAssets 返回的 assets 的底层缓存
  // 但 assets 是 state，需要 setAssets...
}, [])
```

**更好的方案**：让 useRealAssets 暴露一个 `patchLocal(assetId, patch)` 方法：

文件：`src/components/assetManager/useRealAssets.ts`

```typescript
// 在返回值中加：
const patchLocal = useCallback((assetId: number, patch: Partial<AssetDetail>) => {
  setAssets(prev => prev.map(a => a.id === assetId ? { ...a, ...patch } : a))
  // 同时更新缓存
  const cached = cacheMap.get(pid)
  if (cached) {
    cacheMap.set(pid, cached.map(a => a.id === assetId ? { ...a, ...patch } : a))
  }
}, [pid])

return { assets, loading, error, reload, patchLocal }
```

#### D4. handleSelect 改为三态流转 + 乐观更新

```typescript
const handleSelect = async (assetId: number, groupKey: string) => {
  const sameGroup = assets.filter((d) => getGroupKey(d) === groupKey)

  // 乐观更新：先改 UI
  // 1. 同组旧选定资产 → 淘汰
  for (const d of sameGroup) {
    if (d.isPrimaryView && d.id !== assetId) {
      patchLocal(d.id, { isPrimaryView: false, state: 'eliminated' })
    }
  }
  // 2. 新选定资产 → selected
  patchLocal(assetId, { isPrimaryView: true, state: 'active' })

  // 后端同步（不 await，不 reload）
  for (const d of sameGroup) {
    if (d.isPrimaryView && d.id !== assetId) {
      try { await updateAsset(d.id, { isPrimaryView: false, state: 'eliminated' }) } catch {}
    }
  }
  try {
    await updateAsset(assetId, { isPrimaryView: true, state: 'active' })
    showToast('已设为选定资产', 'success')
  } catch (err) {
    showToast('设置失败: ' + (err as Error).message, 'error')
    // 失败回滚：reload 拉回真实状态
    await reload()
  }
}
```

#### D5. 取消选定 → 同组淘汰恢复待选

```typescript
// 选定 tab 的「取消选定」按钮
onClick={async (e) => {
  e.stopPropagation()
  // 乐观更新：该资产 → 待选
  patchLocal(d.id, { isPrimaryView: false, state: 'active' })
  // 同组淘汰资产 → 恢复待选
  const sameGroup = assets.filter(dd => getGroupKey(dd) === groupKey && dd.id !== d.id)
  for (const dd of sameGroup) {
    if (dd.state === 'eliminated') {
      patchLocal(dd.id, { state: 'active' })
    }
  }
  // 后端同步
  try {
    await updateAsset(d.id, { isPrimaryView: false, state: 'active' })
    for (const dd of sameGroup) {
      if (dd.state === 'eliminated') {
        await updateAsset(dd.id, { state: 'active' })
      }
    }
    showToast('已退回待选资产', 'success')
  } catch (err) {
    showToast('操作失败', 'error')
    await reload()
  }
}}
```
