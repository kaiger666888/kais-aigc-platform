# Task Spec: scene-images DAG 修复 — adapter 层支持 scene_image 类型

## 问题
`scene_image` 类型的 canvas_nodes（44个场景图节点）在 V2→V3 migrate 时被丢弃，因为 `MIGRATE_SUPPORTED_TYPES` 不包含 `'scene_image'`。这导致 DAG 的 scene-images 节点永远 pending（RF nodes 中没有这些节点）。

## 根因
`packages/infinite-canvas/src/v3/adapter.ts` L47-50:
```typescript
const MIGRATE_SUPPORTED_TYPES = new Set([
  'script', 'storyboard', 'video', 'audio', 'asset',
  'upscale', 'face_restore', 'variant', 'reference',
])
```
`'scene_image'` 不在列表中 → `normalizeNodeType` 返回 null → 节点被跳过。

## 修复方案

### 文件：`packages/infinite-canvas/src/v3/adapter.ts`

在 `MIGRATE_SUPPORTED_TYPES` 中添加 `'scene_image'`：
```typescript
const MIGRATE_SUPPORTED_TYPES = new Set([
  'script', 'storyboard', 'video', 'audio', 'asset',
  'scene_image',  // ← 新增
  'upscale', 'face_restore', 'variant', 'reference',
])
```

同时在 `packages/flowgraph-v3/ts/src/migrate.ts` 的 `planNode` 函数中，需要为 `case 'scene_image'` 添加处理（否则会 throw "不支持的 V2 节点类型"）。

在 migrate.ts 的 planNode switch 中添加：
```typescript
case 'scene_image': {
  // 场景图 → global stage, image modality
  return {
    stage: 'global',
    modality: 'image',
    scope: 'global',
    op: 'import',
    executor: 'human',
    orphanEligible: false,
  };
}
```

### 验证
修复后 scene-images DAG 节点应该匹配 44 个节点，状态 completed。
