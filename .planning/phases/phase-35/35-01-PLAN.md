# Phase 35 Plan 01 — Storyboard Metadata Extension

## Goal

Extend `StoryboardNodeData` with 4 directorial-intent fields (camera movement / framing / composition / pacing), render them as chips on the canvas, expose dropdown editors in `NodeDetailPanel`, and rely on the existing JSON blob persistence to round-trip the new fields with zero backend schema change.

## Why This Plan

Phase 35 is a pure frontend + type extension phase. The backend already stores the entire canvasGraph as a JSON blob (`o_agentWorkData.data` keyed by `canvasGraph`), so new fields round-trip automatically. The flowDataMapper uses generic `data: n.data as Record<string, unknown>` spread, so no mapper code changes are needed. This makes Phase 35 a single-plan phase.

## Implementation

### 1. Type extension (`types/canvas.ts`)

Add 4 union types after the `NodeState` definition:

```typescript
export type CameraMovement = 'static' | 'zoom_in' | 'zoom_out' | 'pan_left' | 'pan_right' | 'tilt_up' | 'tilt_down' | 'dolly' | 'tracking'
export type Framing = 'wide' | 'medium' | 'close_up' | 'extreme_close_up' | 'over_the_shoulder' | 'aerial'
export type Composition = 'rule_of_thirds' | 'centered' | 'golden_ratio' | 'symmetrical' | 'leading_lines'
export type Pacing = 'slow' | 'medium' | 'fast' | 'montage'
```

Extend `StoryboardNodeData` with optional fields (after `linkedAssetIds`):

```typescript
cameraMovement?: CameraMovement
framing?: Framing
composition?: Composition
pacing?: Pacing
```

### 3. Renderer chips (`StoryboardNode.tsx`)

Below the existing `linkedAssetIds` row, render a metadata chip cluster:

```tsx
const chips = [
  data.cameraMovement && METADATA_LABELS.cameraMovement[data.cameraMovement as CameraMovement],
  data.framing && METADATA_LABELS.framing[data.framing as Framing],
  data.composition && METADATA_LABELS.composition[data.composition as Composition],
  data.pacing && METADATA_LABELS.pacing[data.pacing as Pacing],
].filter(Boolean)

chips.length > 0 && (
  <div style={{ display: 'flex', gap: 4, flexWrap: 'wrap', marginTop: 4 }}>
    {chips.map((c, i) => (
      <span key={i} style={chipStyle}>{c}</span>
    ))}
  </div>
)
```

### 4. Detail panel editors (`NodeDetailPanel.tsx`)

In `StoryboardDetail`, add a "镜头意图" section with 4 `<select>` elements bound to `useCanvasStore.setNodes` to update the selected node's data.

`StoryboardDetail` needs a new prop: `nodeId: string` (to identify which node to mutate). Add it to the props destructuring.

```tsx
<SectionLabel>镜头意图</SectionLabel>
<MetadataEditor nodeId={nodeId} data={data} />
```

`MetadataEditor` is a new sub-component:

```tsx
function MetadataEditor({ nodeId, data }: { nodeId: string; data: StoryboardNodeData }) {
  const setNodes = useCanvasStore((s) => s.setNodes)
  const setField = (field: keyof StoryboardNodeData, value: string) => {
    setNodes((nds) => nds.map((n) =>
      n.id === nodeId ? { ...n, data: { ...n.data, [field]: value || undefined } } : n
    ))
  }
  // render 4 <select> bound to data.cameraMovement etc.
}
```
