<!-- API contract from docker/hermes-agent/src/api/models.py -->

POST /v1/decide request body (DecideRequest):
  domain: str (required, max 64)
  task: str (required, max 200)
  context: dict (optional, default {})

POST /v1/decide response 200 (DecideResponse):
  decision_id: str (UUID)
  recommendation: str (raw LLM text, NOT JSON-parseable)
  confidence: float (EWMA 0.0-1.0)
  domain: str
  task: str
  timestamp: str (ISO 8601)

POST /v1/audit request body (AuditRequest):
  domain: str (required, max 64)
  decision_id: str (required, max 64)
  outcome: str (default "completed", max 50)
  metrics: dict (optional, default {})

POST /v1/audit response 200 (AuditResponse):
  recorded: bool
  auto_learn_triggered: bool
  decision_id: str

Error responses:
  404: { detail: "Domain 'xxx' not registered" }
  422: { detail: "validation error" }
  502: { detail: "Decision engine error" }

    3. On any failure: log warning and return {recorded: false, auto_learn_triggered: false, decision_id: decisionId}
    4. NEVER throw -- audit is non-blocking per CONTEXT.md
