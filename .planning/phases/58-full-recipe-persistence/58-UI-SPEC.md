# Phase 58 — UI Design Contract

> Visual and interaction contract for 全配方持久化 (Full Recipe Persistence). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope discipline**: this is a SMALL incremental surface INSIDE the existing NodeDetailPanel PromptSection — not a new page. The only new UI: (1) collapsible「高级参数」section (default collapsed), (2) typed controls (number/select/LoRA row editor), (3) readonly catchall display. Everything else is consistency with 52-03 PromptSection / 52-05 StaleSection / catppuccin tokens / 480px panel width.

Exceptions: none. Control heights: 28px (number input, select, LoRA name input), 24px (LoRA remove ✕ hit target renders 20px glyph with 2px padding inside 24px box). LoRA strength input width 72px; field-label column width 88px (`flexShrink: 0`).

Panel geometry (inherited, DO NOT change): default width 480px (min 400, drag-resizable), content padding 16px → 448px usable row width; field row = 88px label + 8px gap + 352px control.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 「保存」— shared with prompt; single save persists the whole recipe (locked: no field-level blur-save). Pending: 「保存中…」 |
| Secondary CTA | 「重生成」(existing, unchanged). Pending: 「提交中…」. Disabled-while-dirty title: 「请先保存，再重生成（防半编辑误触发）」 |
| Section header (collapsed) | 「高级参数 ▸」— default state |
| Section header (expanded) | 「高级参数 ▾」 |
| LoRA empty state heading | 「暂无 LoRA」 |
| LoRA empty state body / next step | 「+ 添加 LoRA」button on the same row — heading states the absence, button is the next step |
| LoRA row editor | Row = name text input (placeholder 「LoRA 名称」) + strength number input + ✕ remove. Add button: 「+ 添加 LoRA」 |
| Catchall group label | 「其他（只读）」— pipeline-private fields outside KNOWN_KEYS, readonly KvRows |
| Advanced all-empty state | 「暂无高级参数」hint when expanded and event has no steps/cfg/quant/sageAttention/lora/catchall values |
| Seed readonly caption | 「在事件芯片 popover 换 seed 重跑」— seed is display-only here (locked: seed editing lives in the popover reroll channel) |
| Error state (save) | 「配方保存失败已回滚: {message}」— store-emitted toast + surgical rollback (existing, verbatim) |
| Error state (regen) | 「重生成提交失败: {message}」(existing) · guard: 「缺少项目上下文」warning (existing) |
| Destructive confirmation | **None required.** LoRA row removal is draft-level (revertible by not saving or re-adding); no confirm dialog. No hard-destructive action exists in this phase |

**Readonly-state hint copy is e2e-locked and MUST NOT change**: 落选变体 → 「落选变体配方已并入主事件 variantRecipes，不可单独编辑」; 无事件 → 「无产生事件，prompt 不可编辑」 (phase52 tests assert `prompt-readonly-hint` contains 「落选变体」).

## Phase-Specific Component Contract

### 1. 高级参数 collapsible section (inside PromptSection, below the prompt textarea)

- Toggle = full-width button, styling of `SectionLabel` (11px/600/uppercase/0.05em, `theme.text.secondary`) + chevron ▸/▾ + dirty dot; `cursor: pointer`, background none, border none. **Default COLLAPSED** (locked). Collapse state is component-local (resets on node switch — acceptable; no persistence needed).
- Expanded body: transparent background (controls carry `bg.input` themselves, matching how the prompt textarea sits on the panel), flex column, gap 8px, marginTop 8px.
- Field row layout: label 88px left (`theme.text.secondary`, 11px) + control flex 1 right. Readonly rows reuse the panel `KvRow` pattern (secondary label + mono primary value).

### 2. Typed controls (field → control mapping, locked in CONTEXT)

| Field | Control | Details |
|-------|---------|---------|
| steps | `input[type=number]` | integer, min 1, max 100, step 1; empty = unset |
| cfg | `input[type=number]` | decimal, min 0, max 20, step 0.5; empty = unset |
| quant | native `select` | options: 未设置(undefined) / fp8 / fp16 / int8 / bf16 — **plus rule: if canonical value ∉ option list, inject it as an extra selected option** (never silently coerce or drop — RECIPE-03 fidelity) |
| sageAttention | native `select` | options: 未设置(undefined) / 是(true) / 否(false) |
| lora | row editor | rows of [name text input + strength number (min −1, max 2, step 0.05) + ✕ remove]; 「+ 添加 LoRA」 appends `{ name: '', strength: 1 }`; new-row default strength 1 |
| seed | readonly row | mono value + caption (see copywriting) — NOT editable here (popover owns seed) |
| modelVersion | readonly row | mono value |
| catchall (non-KNOWN_KEYS) | readonly KvRows | values via `JSON.stringify` for objects/arrays (popover catchall precedent) |

Control styling: background `theme.bg.input`, border 1px `theme.border.default`, radius 6px, padding 4px 8px, fontSize 12, height 28px, color `theme.text.primary`; focus border `theme.border.strong`. Disabled state: color `theme.text.disabled`, cursor default. Add/remove buttons are ghost style (background none, `theme.text.secondary`, hover `theme.text.primary`).

### 3. Editable field whitelist — single source of truth

`RECIPE_EDITABLE_FIELDS` exported from flowgraph-v3 (Claude-discretion recommendation honored: flowgraph-v3 export; panel + popover KNOWN_KEYS import the same constant — one definition, two consumers). Panel-editable advanced set: `steps, cfg, quant, sageAttention, lora`. Display-only known keys: `seed, modelVersion`. Catchall: everything else, readonly.

### 4. State machine (extends 52-03 three-state — no new states)

| State | Trigger | UI |
|-------|---------|-----|
| Editable | producing event found AND curation ≠ deprecated | controls enabled; toggle expandable; save enabled when dirty |
| Readonly-locked | loser variant (`curation === 'deprecated'`) | whole PromptSection disabled incl. advanced controls (values still viewable by expanding); existing `prompt-readonly-hint`; save/regen disabled |
| Readonly-no-event | no producing event (fixture/import-without-event edge: import WITH event stays editable) | same as readonly-locked |

### 5. Dirty / save / regen semantics (locked patterns, extended)

- `dirty = promptDirty || stepsDirty || cfgDirty || quantDirty || sageDirty || loraDirty` (deep-compare lora rows). One shared 保存 button governs the whole editor.
- Save patch = **dirty fields only**; cleared number / 未设置 select → `undefined` in patch (store `updateEventParams` deletes the key → pipeline default); lora = whole-array replacement; blank-name rows (post-trim) dropped; resulting empty lora array → field deleted.
- Regen body: `params: { ...evt.params }` full canonical bag spread (unedited quant/lora/etc pass through byte-untouched — RECIPE-02/03); regen stays disabled while dirty (防半编辑误触发, locked).

### 6. Popover (EventParamsPopover) — explicitly UNCHANGED visually

Readonly grouped display + 「🎲 同配方换 seed 重跑」 stay as-is; only the `KNOWN_KEYS` import source swaps to the shared constant. No new controls, no copy changes.
