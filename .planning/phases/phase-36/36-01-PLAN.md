# Phase 36 Plan 01 — One-Click Film Orchestrator

## Goal

Single "🚀 一键成片" button runs the entire canvas node graph end-to-end in topological order, skipping already-successful nodes, broadcasting live progress via WebSocket, and surfacing a clear completion toast with failed-node list.

## Why This Plan

The existing `execute.ts` already simulates per-node execution with WebSocket broadcasts. The orchestrator wraps that logic in a topology-ordered loop, reusing `broadcastToProject` for progress events. The backend has no real engine concurrency model yet (GpuScheduler is in gold-team, separate from this canvas API), so we keep the per-node simulation pattern and let the orchestrator iterate sequentially.

## Implementation

### 1. Backend route `src/routes/canvas/orchestrate.ts` (NEW)

```typescript
router.post("/", validateFields({
  projectId: z.number(),
  episodesId: z.number(),
  nodeIds: z.array(z.string()).optional(),
}), async (req, res) => {
  const { projectId, episodesId, nodeIds } = req.body
  const runId = `run-${Date.now()}`

  // Load graph
  const row = await u.db("o_agentWorkData")
    .where("projectId", String(projectId))
    .andWhere("episodesId", String(episodesId))
    .andWhere("key", "canvasGraph").first()
  if (!row?.data) return res.status(404).send(error("无画布数据"))

  const graph = JSON.parse(row.data)
  const allNodes = (graph.nodes ?? []) as { id: string; type: string; state?: string }[]

  // Filter + order by topology
  const TOPOLOGY = ["script", "asset", "storyboard", "video", "audio"]
  const targets = (nodeIds ? allNodes.filter((n) => nodeIds.includes(n.id)) : allNodes)
    .filter((n) => n.state !== "success" && n.state !== "cached")
    .sort((a, b) => TOPOLOGY.indexOf(a.type) - TOPOLOGY.indexOf(b.type))

  const total = targets.length
  res.status(200).send(success({ runId, total }))

  setImmediate(async () => {
    let completed = 0, failed = 0
    const failedNodes: string[] = []
    broadcastToProject(projectId, "orchestrate:start", { runId, total })
    for (const node of targets) {
      broadcastToProject(projectId, "orchestrate:progress", {
        runId, completed, total, failed, currentNodeId: node.id,
      })
      try {
        // Reuse simulateExecution pattern
        await simulateExecution(projectId, node.id)
        broadcastToProject(projectId, "node:state", { nodeId: node.id, state: "success" })
        completed++
      } catch (err) {
        broadcastToProject(projectId, "node:state", { nodeId: node.id, state: "error" })
        failed++
        failedNodes.push(node.id)
      }
    }
    broadcastToProject(projectId, "orchestrate:done", {
      runId, completed, total, failed, failedNodes,
    })
  })
})
```

Extract `simulateExecution` to a shared helper (`src/routes/canvas/_simulate.ts`) so `execute.ts` and `orchestrate.ts` both reuse it.

### 3. Frontend `canvasApi.ts`

```typescript
export async function orchestrateCanvas(
  projectId: number, episodesId: number, nodeIds?: string[],
): Promise<{ runId: string; total: number }> {
  const json = await apiCall<{ data: { runId: string; total: number } }>(
    '/canvas/orchestrate',
    { projectId, episodesId, ...(nodeIds && { nodeIds }) },
  )
  return json.data
}
```

### 5. WebSocket hooks

`useCanvasSocket.ts` adds three new event handlers:

```typescript
socket.on('orchestrate:start', (p) => onStart({ runId: p.runId, total: p.total, mode }))
socket.on('orchestrate:progress', (p) => onProgress(p))
socket.on('orchestrate:done', (p) => onDone(p))
```

The hook gets a new prop `mode` so 'full' vs 'batch' is differentiated.

### 6. Toolbar button

Add to FlowCanvas.tsx top-left Panel after the existing toolbar buttons:

```tsx
<ToolbarButton
  onClick={handleOrchestrate}

    ? `🚀 运行中 (${orchestration.completed}/${orchestration.total})`

{orchestration.status === 'running' && (
  <ProgressBar completed={orchestration.completed} total={orchestration.total} />
```

`handleOrchestrate` calls `orchestrateCanvas(projectId, episodesId)` and sets local state.

On `orchestrate:done`, show toast: `一键成片完成 (${completed}/${total} 节点成功)` + failed-node detail.
