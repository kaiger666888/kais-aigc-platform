**Accent（金）reserved for——完整清单,仅此 4 处:**

1. Topbar 待办 chip 的呼吸圆点 + 边框 + 「等你决策」四字;
2. 阻塞 phase 列的呼吸描边(双层 stroke) + 列竖带提亮(0.04→0.08) + 该列 `P0X` 前缀文字;
3. Gate 面板内**当前阻塞门那一行**的状态点与状态标签（其余 pending 档非阻塞行用 `signal.pending` 中性灰点——16 门串行,同时至多一个真阻塞）;
4. 动作成功后的瞬时确认反馈（toast 边/图标, ≤2s 消失）。

**四态显示色映射（D-04 四态 × RESEARCH §F.3 候选定案,U-08）:**

|--------|----------|-------|-----|---------|

- `放行` = primary 冷白（`theme.button.primary` #EDEEF1 填充 + `text.onAccent`）;
- `驳回` = danger 玫（`theme.button.danger`）;
- `豁免` = ghost（`theme.button.ghost` 底 + `signal.locked` 描边与文字）——豁免是冷灰的刻意动作。

### C-1 Topbar 待办 chip（`GateTodoChip`）
- **落位**: FlowCanvas topbar 右簇（`FlowCanvas.tsx` L791-797 connection 指示旁,`gap:8` 容器内、连接点左侧）。
- **形态**: 高 26px 圆角 7px（对齐顶栏既有 ViewMode 控件族）,底 `--cv-bg-overlay`,边 1px 金(alpha 0.55),内距 `4px 12px`;内容 = 10px 呼吸圆点（金）+ `等你决策 · {门名}` 12px/400,「等你决策」四字 600 金色,门名 `text.secondary`。

- `data-testid="gate-todo-chip"`。

### C-2 PhaseColumns 阻塞列处理
- **改点**: `PhaseColumns.tsx` 增可选 prop `blockingPhaseIndex?: number | null`（纯展示,`pointer-events:none` 保持;由 FlowCanvas 从 gateStore 传入）。

### C-4 理由输入 + 二次确认对话框（驳回/豁免共用）
- 53-07 D-14 模式: 组件内 state `confirming: 'reject' | 'waive' | null`,**绝不用原生 confirm()**。
- 流程: 点击驳回/豁免 → 理由对话框（标题 = Destructive confirmation copy,textarea min-height 80 圆角 6 底 `--cv-bg-card`,**必填 min 1 max 500**——对齐平台 RejectRequest 契约）→ [取消] ghost / [确认驳回] 玫填充 或 [确认豁免] locked ghost。
- Esc 取消;焦点圈走 tokens.css 既有 `:focus-visible` 规则。

### C-5 gateStore（zustand,独立 store——P5 纪律）
- `gateStore`: `{ snapshot: GateStatePayload | null, degrade: boolean, open, setOpen(v), apply(payload) }`;payload = RESEARCH §D.2 的**四态折叠后展示模型**（`display ∈ pending|approve|reject|waive|auto`）——平台原始态(POLICY_EVAL/disposition)不得进前端 payload（D-04）。
- **正交轴铁律**: gate 状态只存在于 gateStore,只经 chip / PhaseColumns / GatePanel 三面呈现;**绝不写节点角标、绝不复用节点 reviewStatus 字段**（右下角标 = 资产轴 WRITE-02 产权,gate = 管线轴）。

## State & Interaction Contract

| 状态/交互 | 契约 |
|-----------|------|
| 新会话打开画布 | loadCanvas 并行 fetch `GET /api/canvas/v2/gate-state`（不阻塞首帧）;有阻塞 → chip 即现 → 一次点击定位（GATE-02 SC2） |
| gate:state socket 事件 | payload 级 memo 浅比较后再 setState（P6 广播风暴防线）;diff 由服务端负责 |
| 放行 | 单点击 → 行转「处理中…」→ await gate-ops → 成功翻 approve 态 + toast;失败回滚 + toast |
| 驳回 / 豁免 | 理由必填 + 二次确认 → 同上乐观翻转 |
| 409 already-resolved | **幂等成功语义**: 行刷新为实际态 + 409 toast,P4 禁当错误弹 |
| 平台不可达 | 连续轮询失败 → 降级横幅 + fetchedAt 变旧标注;**绝不折叠为全放行**（fail-closed 展示）;chip 在降级期间保持（有 last-known blocking 时）但降级样式待定不加新色 |
| blocking 消失（已决策） | 列描边/竖带/chip 全部退场动画 `--cv-d-unhighlight` 220ms;面板行翻终态 |
| 键盘 | Esc 关面板/关对话框;`/` 搜索等既有快捷键不受影响;新可点元素全部走 `:focus-visible` 冷白描边 |
| prefers-reduced-motion | 呼吸/脉冲全部静止（静态 strokeOpacity 0.7、chip 点常亮）;沿用 tokens.css 既有降级块 |

**代表节点解析序**（chip 跳焦）: `g-{gate_id}` review 节点 → `n-{phase_id}` phase 节点 → 该 phaseIndex 首个资产节点;三者皆无时只开面板不跳焦（不报错）。

## Anti-Patterns（Do-Not 清单——设计检查步逐条对照）

1. **禁止红溅画布**: 玫色只允许出现在 ≤10px 状态点、11px 状态标签、驳回按钮、降级横幅边。禁止玫色列带/节点描边/大面积填充。
2. **禁止 gate 状态上节点角标**: 四角产权制已满（右上 score/左下 stale/右下 reviewStatus/左上 C 层预留）,gate 是管线轴（P5）。
3. **禁止新 hue / 新 hex / 新动效节拍**: 全部引用 `v3theme.*` / `--cv-*`;alpha 衍生仅限既有 Weak 先例。
4. **禁止原生 confirm()/alert()**: 二次确认一律组件内 state 对话框（53-07 先例）。
5. **禁止暴露平台内部态**: POLICY_EVAL / APPROVING / disposition / review_id 裸值不上 UI（review id 只进 mono 标注与日志）。
6. **禁止空态占位**: 无阻塞 = chip 不渲染、工具栏徽章不显示,不做「0 待办」噪音。
7. **禁止一次性 zone hack**: 阻塞定位走 PhaseColumns median 投影 + 既有节点键,Phase 55 zone 重构后必须仍成立。
8. **禁止全屏 loading**: 状态切换一律行级「处理中…」。
