# Phase 38 Plan 01 — Storyboard Preview Cards

## Goal

Tier 2 (optional) capability borrowed from Xiaoyunque: generate a static 1280×720 composition preview image for a storyboard *before* committing to video generation. Reduces iteration cost on misframed shots.

## Implementation

### 1. Backend route `src/routes/canvas/storyboardPreview.ts` (NEW)

Reuses the same `simulateExecution` pattern as execute.ts (placeholder for real IMAGE_DRAW engine call). Returns immediately, broadcasts `node:preview` when done.

```typescript
router.post("/", validateFields({
  projectId: z.number(),
  episodesId: z.number(),
  nodeId: z.string(),
}), async (req, res) => {
  const { projectId, nodeId } = req.body
  if (!nodeId.startsWith("storyboard-")) {
    return res.status(400).send(error("仅分镜节点支持预览"))
  }
  res.status(200).send(success({ nodeId, status: "preview_triggered" }))

  setImmediate(async () => {
    try {
      // TODO: real engine call: gold-team IMAGE_DRAW with prompt + linkedAssetIds
      // For now, simulate delay + broadcast a placeholder thumbnail
      await new Promise(r => setTimeout(r, 4000))
      broadcastToProject(projectId, "node:preview", {
        nodeId,
        thumbnailUrl: null, // Real implementation: post-processed asset URL
        state: "preview_ready",
      })
      broadcastToProject(projectId, "node:state", { nodeId, state: "idle" }) // do not pollute main state
    } catch (err) {
      broadcastToProject(projectId, "orchestrate:done", { failedNodes: [nodeId], ...placeholder })
    }
  })
})
```

### 2. Wire route

`src/router.ts`:
```typescript
import routeStoryboardPreview from "./routes/canvas/storyboardPreview";
app.use("/api/canvas/storyboard/preview", routeStoryboardPreview);
```

### 3. Frontend API client

```typescript
export async function previewStoryboard(
  projectId: number, episodesId: number, nodeId: string,
): Promise<void> {
  await apiCall<void>('/canvas/storyboard/preview', { projectId, episodesId, nodeId })
}
```

### 4. StoryboardNode — preview button

Below the existing thumbnail (or as overlay), add a button:

```tsx
const canPreview = (data.linkedAssetIds as number[])?.length > 0 && !!(data.prompt as string)
<button
  disabled={!canPreview}
  onClick={async (e) => {
    e.stopPropagation()
    try {
      await previewStoryboard(projectId, episodesId, id)
      showToast('预览生成中...', 'info')
    } catch (err) { showToast('预览触发失败', 'error') }
  }}
>
  👁 预览构图
</button>
```

The button needs access to `projectId`/`episodesId` — pass via props from the canvasStore, or use `useCanvasStore.getState()` to fetch them directly inside the click handler.

### 5. WebSocket event reuse

The existing `useCanvasSocket` already handles `node:preview` → calls `onNodePreviewUpdate` which sets `thumbnailUrl`. Works as-is.
