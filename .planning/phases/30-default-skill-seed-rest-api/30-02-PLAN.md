**File 3: src/routes/v1/skills/register.ts** — `POST /api/v1/skills/register`

This is the most complex handler. Per CONTEXT.md D-05: skip `validateFields` middleware and call `validateManifest()` directly so we can echo its errors verbatim. The flow is:

1. Read manifest from `req.body` (no zod pre-validation — we want the validator's structured errors, not zod's body-parser errors).
2. `const result = validateManifest(req.body);`
3. If `result.ok === false`: return `400 { ok: false, errors: result.errors }` — the errors array is sent verbatim (Phase 33 asserts on `errors[0].ruleId`). Do NOT mutate the DB or registry.
4. If `result.ok === true`: the manifest is valid. UPSERT into `o_skillRegistry`:
   ```typescript
   await u.db("o_skillRegistry")
     .insert({
       skill_id: result.value.skill_id,
       manifest_json: JSON.stringify(result.value),
       version: result.value.version,
       active: 1,
       registered_at: Date.now(),
     })
     .onConflict("skill_id")
     .merge();   // SQLite UPSERT — re-registering an existing skill_id overwrites the row
   ```
5. Call `registry.register(result.value)` to update the in-memory cache without restart. Wrap in try/catch — register() re-validates and could theoretically throw if a future code path bypasses validation. On catch, return `500 { ok: false, error: "registry update failed: <msg>" }`. (This is defensive — in practice validateManifest already passed, so register will not throw. But the registry.register contract documents that it throws on invalid input, so the handler must honor that contract.)
6. Return `201 { ok: true, skill: { skill_id: result.value.skill_id, version: result.value.version, display_name: result.value.display_name } }` — echoes a summary, not the full manifest (caller just sent it).

Full file shape:
```typescript
import express from "express";
import u from "@/utils";
import { validateManifest } from "@/skills/validator";
import { registry } from "@/skills/registry";

const router = express.Router();

export default router.post("/", async (req, res) => {
  const result = validateManifest(req.body);
  if (!result.ok) {
    return res.status(400).send({ ok: false, errors: result.errors });
  }
  const manifest = result.value;
  try {
    await u.db("o_skillRegistry")
      .insert({
        skill_id: manifest.skill_id,
        manifest_json: JSON.stringify(manifest),
        version: manifest.version,
        active: 1,
        registered_at: Date.now(),
      })
      .onConflict("skill_id")
      .merge();
  } catch (err) {
    const msg = err instanceof Error ? err.message : String(err);
    return res.status(500).send({ ok: false, error: `database upsert failed: ${msg}` });
  }
  try {
    registry.register(manifest);
  } catch (err) {
    const msg = err instanceof Error ? err.message : String(err);
    return res.status(500).send({ ok: false, error: `registry update failed: ${msg}` });
  }
  res.status(201).send({
    ok: true,
    skill: {
      skill_id: manifest.skill_id,
      version: manifest.version,
      display_name: manifest.display_name,
    },
  });
});
```
