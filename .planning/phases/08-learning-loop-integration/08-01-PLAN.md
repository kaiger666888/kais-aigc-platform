    Create docker/hermes-agent/src/core/domain_memory.py with the DomainMemory class.

    Class constructor takes memory_dir: Path. Stores self.memory_dir and self.history_path = memory_dir / "audit_history.json".

    Module-level constants:
    - EWMA_ALPHA = 0.3
    - AUTO_LEARN_THRESHOLD = 0.5
    - MIN_AUDITS_FOR_CONFIDENCE = 3
    - MAX_RECORDS_PER_TASK = 100
    - RECENT_RECORDS_LIMIT = 10

    Private methods:
    - _load_history() -> dict[str, Any]: Read audit_history.json. Return {} if file missing or corrupt (catch json.JSONDecodeError, OSError).
    - _save_history(data: dict[str, Any]) -> None: Atomic write (write .tmp then rename, matching Phase 7 pattern in domain_registry.py).
    - _prune_task(task_data: dict[str, Any]) -> None: Keep only last MAX_RECORDS_PER_TASK records.
    - _compute_ewma(records: list[dict[str, Any]]) -> float: Extract score from each record's metrics.score field. Normalize: if score > 1.0 divide by 10.0, clamp to 0.0-1.0. If fewer than MIN_AUDITS_FOR_CONFIDENCE records, return 0.0. Otherwise compute EWMA: ewma = normalized[0], then ewma = alpha * score + (1-alpha) * ewma for each subsequent. Round to 4 decimal places.
    - _trend(scores: list[float]) -> str: If < 4 scores return "stable". Compare avg of last 3 vs avg of earlier. If recent > earlier * 1.1 return "improving". If recent < earlier * 0.9 return "declining". Else "stable".
    - _normalize_score(raw) -> float: Handle TypeError/ValueError by returning 0.0. If val > 1.0 divide by 10.0. Clamp to 0.0-1.0.

    Public methods:
    - append_record(task: str, record: dict[str, Any]) -> None: Load history. If task not in history, init with {"records": [], "ewma_confidence": 0.0}. Append record to records list. Call _prune_task. Recompute EWMA via _compute_ewma. Save history.
    - get_confidence(task: str) -> float: Load history. Return task_data.get("ewma_confidence", 0.0). Return 0.0 if task not found.
    - should_trigger_auto_learn(task: str) -> bool: Load history. Return False if task not found or records < MIN_AUDITS_FOR_CONFIDENCE. Return True if ewma_confidence < AUTO_LEARN_THRESHOLD.
    - get_summary() -> dict[str, Any]: Load history. Build task_stats dict: for each task, compute avg_score (average of normalized scores), record_count, ewma_confidence, trend_direction. Collect recent 10 records across all tasks sorted by timestamp desc. Return {"task_stats": task_stats, "recent_records": recent_records[:RECENT_RECORDS_LIMIT]}.

    Do NOT import any external packages. Only use json, pathlib.Path, typing.Any from stdlib.
  </action>
