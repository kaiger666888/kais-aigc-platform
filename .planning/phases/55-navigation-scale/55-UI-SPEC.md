## Spacing Scale

Declared values（全部 4 的倍数，与既有面板 token 对齐）：

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 图标-文字间隙、树行内元素 gap（ShotTree 既有 `gap: 2` 保留为 hairline 例外） |
| sm | 8px | 紧凑行内边距（TreeItem `padding: 4px 8px` 既有）、chip 内距 |
| md | 16px | 面板内边距（`--cv-panel-pad: 16px` 既有）、卡片内距 |
| lg | 24px | 分区间隔（`--cv-panel-section-gap: 24px` 既有）、统计栏上下 |
| xl | 32px | 空态卡内距（FlowCanvas 欢迎卡 `32px 48px` 既有） |
| 2xl | 48px | 带间凹槽（`--cv-lane-gap: 48` 既有）、空态卡左右 |

Exceptions（均为既有值，新代码不得再发明例外）：
- 2px：hairline 元素间隙（ShotTree 既有）
- 12px：既有全局列间隙（V3_LAYOUT.GLOBAL_COL_GAP）；新表面不使用
- 28px：ShotTree 折叠轨宽（既有）+ **新交互行最小高度 28px**（导航器结果行、树行、分支行——键盘/鼠标可命中下限）
- 44px：VT 折叠宽（既有 StoryboardTimeline，不动）

93 镜规模约束：导航器面板 `max-height: 60vh` 内部滚动；场景浏览器按场景分组渲染（单场景 ≤ ~25 卡），**禁止任何 93 行平铺列表**。

## Typography

严格复用 `--cv-fs-t1..t4`（`--cv-fs-t5: 9px` 仅为 ShotTree 既有 uppercase 分类头保留，不扩展到新表面）：

| Role | Size | Weight | Line Height | Token |
|------|------|--------|-------------|-------|
| Heading（面板标题/场景节头） | 14px | 600 | 1.2 | `--cv-fs-t1` |
| Body（正文/提示文案） | 12px | 400 | 1.6 | `--cv-fs-t2` |
| Label（列表行/镜头卡字段/chip） | 11px | 400 | 1.4 | `--cv-fs-t3` |
| Micro（计数/辅助注/kbd 提示） | 10px | 400 | 1.4 | `--cv-fs-t4` |

- 权重**只有 400 + 600 两档**（仓内 500/700 是遗留组件用法，新表面禁用）。
- body line-height 1.6 是仓内主导值（22 处，CJK 友好）；heading 1.2。
- ID 类文本（shot_id、P0X、EP 号、分支计数）一律 `--cv-font-mono`。
- 文案全部中文（审片行话），禁止英文-only 标签；专有缩写（LOD/promPT 字段名）可保留英文于 tooltip。

## Color

延续 v2「冷中性壳 + 暖模态通道」——颜色只留给内容与结构维度，表面全冷中性：

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0A0B0E`（`--cv-bg-canvas`）+ `#111317`（`--cv-bg-panel`） | 画布底、顶栏、面板壳 |
| Secondary (30%) | `#16181D`（`--cv-bg-card`）/ `#1E2128`（`--cv-bg-overlay`） | 导航器面板、镜头卡、树/分支面板、浮层；hover `--cv-bg-card-hover #1E2128` |
| Accent (10%) | `#EDEEF1`（`--cv-select` 冷白） | 见下方 reserved-for 清单 |
| Destructive | `#DD6A82`（`--cv-mod-video` 玫，仓内 danger 语义复用） | 仅「升为主线」二次确认态与分支持久化失败 toast |

Accent (`#EDEEF1` 冷白) reserved for（穷举，绝不上「所有交互元素」）：
1. 导航器当前键盘/悬停激活行（左侧 2px 实线 + `rgba(237,238,241,0.10)` 底——ShotTree TreeItem active 同款）
2. 键盘焦点环（既有 `tokens.css` `.cv-search-input:focus-visible, button:focus-visible` 的 2px outline——**不得删除**）
3. 「升为主线」主按钮（冷白底 `--cv-text-on-accent` 深字）
4. 被选中镜头卡/分支行的描边（`--cv-glow-select`）

彩色通道二维映射（同一套 4 hex，两个正交维度——**这是 token 体系设计意图，非 bug**）：
- **场景维度**（本期签名元素，见下节）：`VT_SCENE_COLORS = [image 青 `#56B89A`, video 玫 `#DD6A82`, audio 橙 `#E08547`, text 金 `#E0B665`]`，按 `sceneNumOf(shotId)-1) % 4` 循环。只允许出现在：场景分组表面（导航器场景头、场景节头、镜头卡色带）。
- **阶段维度**（Phase 54 同族，D-04 单一注册表消费）：`v3theme.phaseGroup = {research 金, story 青, production 玫, post 橙}`。只允许出现在：PhaseColumns 列头/竖带、泳道分组标签。Phase 54 阻塞高亮同坐标系同 token，本期不得另起色值。
- **未映射 zone（NAV-01 兜底）**：不用 phaseGroup 色，用 `--cv-stale #F0A52E`（fail-loud 信号语义：列头文字 + 竖带 opacity 0.04→0.08 加倍 + 左边界线 1px `--cv-stale-weak`），配 `console.warn`——醒目但不崩（D-03）。
- 两维度不得在同一表面同时做颜色编码（导航器/场景浏览器只见场景色带；画布 PhaseColumns 只见 phaseGroup 色）。

## Signature Element：场景色带（Scene Ribbon）

本期唯一记忆点——把 StoryboardTimeline 的 `VT_SCENE_COLORS` 场景色带语言延伸到全部新导航表面。具体规格：

1. **场景节头**（导航器分组头 + 场景浏览器节头）：左侧 3px 竖色带（场景色 100%）；文本语法沿用 PhaseColumns 标签文法——场景号 mono 11px 场景色 + 名称/计数 11px `--cv-lane-label`（`rgba(154,159,168,0.55)`）。
2. **镜头卡**：左缘 3px 场景色带（同 `--cv-node-modbar-w: 3px` 节点模态边条规格）；缩略图缺失时底色 `${sceneColor}33`、有图时 `${sceneColor}22`（VT 既有公式）。
3. **导航器结果行**：行首 8px×8px 圆角色点（场景色）替代整行染色，保证列表扫读低噪声。
4. 色带函数与 `sceneNumOf` 从 StoryboardTimeline 抽出共享（research 已列两侧口径不一：`sceneNumOf` 数字段法 vs `scenePrefix` 分隔符法——**统一用 `sceneNumOf` 口径**，planner 落地为共享 util + 单测）。

## Component Inventory & Interaction Contract

### 1. SearchNavigator（NAV-03，新组件）
- 触发：`/` 全局 keydown（**守卫：e.target 非 input/textarea/contentEditable**——Pitfall 7）；Esc 关闭。工具栏搜索框点击亦打开（输入框保留为入口，删除的是 hidden 过滤）。
- 形态：画布居中偏上浮层（`top: 15vh` 居中，宽 `min(560px, 90vw)`，`--cv-bg-panel` 底 + `--cv-shadow-pop` + `backdropFilter: blur(4px)`——ShotTree 浮层同款）。
- 结构：搜索输入（复用 `.cv-search-input` 类与既有样式）→ 结果列表**按场景分组**（sticky 场景头带场景色点 + mono 场景号 + 计数）→ 底部键位提示条。
- 索引：label / shot_id / prompt 摘要（video_prompt·raw 白名单字段）；客户端即时过滤（93 镜 <10ms，无 debounce 必要，≤100ms 上限）。
- 键盘：↑↓ 跨组移动（组头可跳过）、Enter 跳转、Esc 关闭；`role="dialog"` + `aria-label="搜索导航器"`。
- 点击/Enter → `setFocusAssetNodeId(id)`（复用既有 effect：fitView duration 600 / maxZoom 1.5 / 1.5s 清空——**语义不得改**）。
- **必删**：FlowCanvas 608-626 的 hidden 过滤 useEffect 整段（93 镜下「闪空」反模式）。

### 2. SceneShotBrowser 场景→镜头两级浏览（NAV-02）
- 宿主：独立面板/视图模式（StoryboardBoard 两级视觉先例 + `extractShots()` graph 派生数据——board JSON 数据源弃用，Pitfall 6）；入口放工具栏（film 图标 + 「分镜浏览」）。
- 层级语义：场景节头（可折叠，defaultOpen 首场景——StoryboardBoard 先例）→ 镜头卡网格 `repeat(auto-fill, minmax(200px, 1fr))`。
- 镜头卡信息密度（上=主，下=次）：
  - **一级（常显）**：16:9 缩略图（首帧→缩略图→色带底降级）、`shot_id`（mono 11）+ 时长 chip、景别·运镜两枚 chip（`METADATA_LABELS` 中文枚举）、左缘场景色带。
  - **二级（hover 展开）**：画面提示 2 行截断（11px secondary）、引用行——角色/场景 24px 圆角缩略图横排（回查 scope='global' 节点，ShotTree 全局栏同源）+ 名称 10px。
- 交互：单击卡 → 跳画布聚焦（focusAssetNodeId）；节头折叠保留计数与时长。

### 3. PhaseColumns 列头聚焦 affordance（NAV-05）
- 列头 hover/Enter 出现 chip「聚焦本阶段」→ 点击 fitView 该列节点集合 + 恢复记忆 zoom（`laneZoom` 存 `useCanvasPersistence` patch，key 沿 `kais:canvas:v1:p{pid}:e{eid}`）。
- 恢复 zoom 下限 **0.6（L2，keyFields 可读）**；**默认 fitView 行为与 FITVIEW_MIN_ZOOM=0.4 完全不动**（八月盲区修复成果，见 Do-Not-Regress）。
- PhaseColumns 由 `pointer-events:none` 改为仅列头热区可点（SVG 内独立交互层，不挡节点）。

### 4. 未映射 zone 呈现（NAV-01）
- 失败要响：列头「未映射 · N 节点」+ `--cv-stale` 琥珀处理（见 Color）；console.warn 逐节点一条聚合。
- 断言口径：全量 episode **导入后**未映射区为空（存量 pre-W6 图走 fallback 不算失败——research Pitfall 1）。

### 5. BranchPanel 重写（NAV-06）
- 侧栏浮层（ShotTree 同款 overlay 语法，宽 `--cv-panel-w-min: 360px`）；标题「分支与结局」。
- 行结构：分支名 + 父分支链（mono 10px `← {parent}`）+ 状态徽章（主线=冷白底深字「主线」；其余无徽章）。
- 多结局探索两段式：**预览**（临时高亮该分支、其余 `--cv-dim-opacity 0.25` 压暗，再点复原——非破坏）→ **升为主线**（内联二次确认 → `selectBranchAsMain` + REST PATCH 持久化 + 失败回滚 toast）。
- 消费 `store.branches` + `selectBranchAsMain`；status 真相源走 REST 合并（research Pitfall 4 方案 b）。

### 6. 新资产落点（NAV-04，无 UI 面）
- 有事件源：源节点右上偏移（+24px, +16px，4px 网格对齐）；无源：当前视口中心（8px 网格对齐）。到达后复用 `--cv-glow-select` 1.5s 提示。断言=坐标与源/视口距离有界（research 口径）。

## Do-Not-Regress（执行器红线）

1. **LOD 本体不可动**：`useLod.ts` 阈值 L0<0.22 / L1 0.22–0.6 / L2≥0.6、迟滞 0.03、`FITVIEW_MIN_ZOOM=0.4`、LodProvider 单一 viewport 订阅。NAV-05 只许消费侧+持久化层。⚠️ 已知镜像漂移：`tokens.css` 的 `--cv-lod-l0-max: 0.35 / --cv-lod-l1-max: 0.8` 与 `useLod.ts` 不一致——**以 useLod.ts 为权威，本期不顺手"修复"任何一侧**（修值即回归风险，留给 planner 显式裁决）。
2. **focusAssetNodeId effect 语义**（FlowCanvas:700-721）：fitView duration 600 / maxZoom 1.5 / 1.5s 清空 / 未放置 toast——只复用不改。
3. **hidden 过滤必删**：不得保留任何「隐藏非命中节点」路径。
4. **Phase 54 泳道阻塞高亮**：同坐标系（computePhaseColumns）、同 phaseGroup token——本期 22-phase 扩表后 54 的视觉不得变色/换坐标系。
5. **键盘焦点可见性**：`tokens.css` 末段 `:focus-visible` outline 规则保留；新交互元素全部走 `<button>`。
6. **D-04 单一注册表**：所有 phase 词汇（列头文案、zone 名、导航器 phase 过滤）只从扩展后的 22-phase 注册表读，禁止内联中文字符串副本。
