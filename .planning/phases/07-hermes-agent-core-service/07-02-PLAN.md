<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → FastAPI :8080 | Untrusted input: domain names, task names, context dicts, metrics |
| FastAPI → AIAgent.chat() | Trusted: prompt constructed from validated domain data |
| FastAPI → ~/.hermes/domains/ | Trusted: domain names validated before filesystem operations |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | domain name in register/decide/audit | mitigate | Pydantic Field regex pattern `^[a-z0-9][a-z0-9-]{0,62}[a-z0-9]$` validates at API boundary; DomainRegistry also validates at core layer (defense in depth) |
| T-07-02 | Denial of Service | large request bodies | mitigate | Pydantic max_length constraints on string fields; RegisterRequest.tasks capped at 50 items |
| T-07-03 | Tampering | prompt injection via context dict | accept | Context is JSON-serialized into prompt; LLM responses are recommendations only, not executed code. Low risk for internal service. |
| T-07-04 | Information Disclosure | LLM API key in error responses | mitigate | Exception handlers return generic error messages; API keys never included in HTTP responses |
| T-07-05 | Denial of Service | AIAgent.chat() blocking | mitigate | asyncio.to_thread() prevents event loop blocking; consider adding timeout wrapper in Phase 8 |

</threat_model>
