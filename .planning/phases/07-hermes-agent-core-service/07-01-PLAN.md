Create three core modules in `docker/hermes-agent/src/core/`:

1. **domain_registry.py** -- `DomainRegistry` class:
   - Constructor takes `base_dir: Path` (defaults to `Path.home() / ".hermes" / "domains"`)
   - `register(domain, description, tasks, skills_manifest)`: validates domain name with regex `^[a-z0-9][a-z0-9-]{0,62}[a-z0-9]$` (lowercase alphanumeric + hyphens, 2-64 chars), creates `base_dir/{domain}/skills/` and `base_dir/{domain}/memory/` directories, updates `base_dir/registry.json` with domain entry. Creates an empty `base_dir/{domain}/SOUL.md` if it does not exist. Raises ValueError if domain name fails validation.
   - `get(domain) -> dict | None`: reads from registry.json, returns domain config or None
   - `list_all() -> list[str]`: returns all registered domain names
   - `get_skills(domain) -> list[str]`: returns filenames in `base_dir/{domain}/skills/` directory (non-recursive, .md files only, filenames without extension)
   - `domain_exists(domain) -> bool`: convenience check
   - Internal `_load_registry()` and `_save_registry(data)` methods for JSON read/write
   - Handle concurrent access by reading fresh from file each time (no in-memory cache that goes stale)

2. **agent_factory.py** -- `AgentFactory` class:
   - Constructor takes `settings: Settings` (from config.py) and `registry: DomainRegistry`
   - `get_agent(domain: str) -> AIAgent`: looks up domain in registry, loads SOUL.md content from `base_dir/{domain}/SOUL.md`, creates AIAgent instance with: base_url=settings.llm_base_url, api_key=settings.llm_api_key, provider=settings.llm_provider, model=settings.llm_model, platform="api_server", quiet_mode=True, skip_context_files=True (we manage context ourselves), skip_memory=True (we manage memory via domain memory/ dir), ephemeral_system_prompt=SOUL.md content (if non-empty)
   - Raises HTTPException 404 if domain not found (import HTTPException from fastapi)
   - Does NOT cache agent instances -- creates fresh each call (AIAgent state is per-conversation)
   - Import AIAgent using the working import path verified in Task 1 (use `from run_agent import AIAgent`)

3. **decision_engine.py** -- `DecisionEngine` class:
   - Constructor takes `registry: DomainRegistry` and `agent_factory: AgentFactory`
   - `build_prompt(domain, task, context) -> str`: constructs a structured prompt string with format: "Domain: {domain}\nTask: {task}\nContext: {json.dumps(context, ensure_ascii=False)}"
   - `record_audit(domain, decision_id, outcome, metrics) -> dict`: writes a JSON file to `base_dir/{domain}/memory/{decision_id}.json` containing {decision_id, outcome, metrics, timestamp}. Returns {recorded: True, auto_learn_triggered: False}. (auto_learn is Phase 8, always return False for now.)
   - `decide(domain, task, context) -> dict`: validates domain exists via registry, builds prompt via build_prompt, calls agent_factory.get_agent(domain).chat(prompt) wrapped in asyncio-compatible way (the method itself can be synchronous since AIAgent.chat is synchronous -- the async wrapper is in the route layer). Returns {decision_id: uuid4(), recommendation: chat_response, confidence: 0.0, domain, task, timestamp}. confidence is 0.0 static for Phase 7 (dynamic confidence is Phase 8).
   - `check_health() -> dict`: returns {status: "ok", engine: "hermes-agent", domains_count: len(registry.list_all()), domains: registry.list_all()}

4. **__init__.py** -- re-export DomainRegistry, AgentFactory, DecisionEngine for convenient imports.
