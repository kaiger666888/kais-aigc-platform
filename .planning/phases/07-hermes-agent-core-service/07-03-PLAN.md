**conftest.py** -- shared fixtures:
- `tmp_hermes_dir` fixture: creates a temp directory, yields it, cleans up after. Uses `tmp_path` pytest fixture or `tempfile.mkdtemp()`.
- `registry` fixture: creates DomainRegistry with tmp_hermes_dir / "domains" as base_dir. Yields the registry.
- `mock_agent` fixture: creates a mock AIAgent with `chat` method returning a fixed string like "Test recommendation from mock agent". Use `unittest.mock.MagicMock(spec=["chat"])` with `chat.return_value = "Test recommendation"`.
- `agent_factory` fixture: creates a mock AgentFactory whose `get_agent` returns the mock_agent.
- `decision_engine` fixture: creates DecisionEngine with registry and agent_factory fixtures.
- `client` fixture: creates a FastAPI TestClient from src.main.app, with dependency overrides so that get_registry, get_agent_factory, get_decision_engine return the fixture instances. This is critical -- override the deps via `app.dependency_overrides[deps.get_registry] = lambda: registry` etc.

**test_domain_registry.py** -- unit tests for DomainRegistry:
All tests use the `registry` fixture. Test domain registration, validation, listing, skill retrieval, and error cases as listed in behavior above.

**test_routes.py** -- unit tests for API endpoints:
All tests use the `client` fixture (FastAPI TestClient with dependency overrides). Test all 6 endpoints for both happy path and error cases. For decide tests, the mock AIAgent is pre-configured via the dependency override chain.

**test_decision_engine.py** -- unit tests for DecisionEngine:
Test prompt construction format, audit file writing, health check response. Use the decision_engine fixture. For decide tests, the agent_factory mock returns the mock agent.

**test_integration.py** -- end-to-end tests:
- `test_full_flow`: register domain via client -> list domains confirms it -> decide returns recommendation -> audit records it -> verify audit file on disk -> health shows domain
- `test_domain_isolation`: register two domains (domain-a, domain-b) -> decide on domain-a -> verify domain-b memory/ directory is empty (no files) -> confirms DOMAIN-03 isolation
