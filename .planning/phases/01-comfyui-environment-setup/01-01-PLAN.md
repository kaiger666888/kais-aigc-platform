Step 1 -- Clone custom nodes into the Docker named volume.

The Docker named volume `kais-comfyui-custom-nodes` is the persistent store for custom nodes shared across all ComfyUI containers. Use a temporary container with the volume mounted to clone nodes:

```bash
# Use the same base image to ensure git is available
docker run --rm -v kais-comfyui-custom-nodes:/data comfyui-worker:pytorch251-v6-gcc bash -c "
  cd /data &&
  git clone --depth 1 https://github.com/ShmuelRonen/ComfyUI-LatentSyncWrapper.git &&
  git clone --depth 1 https://github.com/cubiq/ComfyUI_IPAdapter_plus.git &&
  git clone --depth 1 https://github.com/cubiq/ComfyUI_InstantID.git &&
  git clone --depth 1 https://github.com/shiimizu/ComfyUI-PhotoMaker-Plus.git &&
  git clone --depth 1 https://github.com/Fannovel16/ComfyUI-Frame-Interpolation.git
"
```

Set HTTP_PROXY and HTTPS_PROXY environment variables on the docker run command: `-e http_proxy=http://host.docker.internal:7890 -e https_proxy=http://host.docker.internal:7890 --add-host=host.docker.internal:host-gateway` to ensure git clone works through the proxy.

IMPORTANT: If any repo fails to clone (e.g., network timeout), retry that specific repo individually. Do NOT proceed to the next task if any clone failed.

Step 2 -- Install pip dependencies for each node inside a temporary container using the ComfyUI base image (same Python 3.10 + PyTorch 2.5.1 environment):

```bash
docker run --rm --gpus all \
  -v kais-comfyui-custom-nodes:/app/ComfyUI/custom_nodes \
  -e http_proxy=http://host.docker.internal:7890 \
  -e https_proxy=http://host.docker.internal:7890 \
  --add-host=host.docker.internal:host-gateway \
  comfyui-worker:pytorch251-v6-gcc bash -c "
    cd /app/ComfyUI/custom_nodes &&
    pip install -r ComfyUI-LatentSyncWrapper/requirements.txt 2>&1 | tail -3 &&
    pip install -r ComfyUI_IPAdapter_plus/requirements.txt 2>&1 | tail -3 &&
    pip install -r ComfyUI_InstantID/requirements.txt 2>&1 | tail -3 &&
    pip install -r ComfyUI-PhotoMaker-Plus/requirements.txt 2>&1 | tail -3 &&
    pip install -r ComfyUI-Frame-Interpolation/requirements.txt 2>&1 | tail -3
  "
```

Watch for dependency version conflicts. The container already has diffusers==0.38.0, torch==2.5.1. If pip wants to downgrade diffusers, reject the downgrade (answer 'n' or use --no-deps for that specific package and install missing deps individually).

Key dependencies expected per node (from RESEARCH.md):
- LatentSync: mediapipe, face-alignment, decord, DeepCache
- IP-Adapter Plus: insightface, onnxruntime-gpu (or onnxruntime)
- InstantID: insightface, diffusers (already satisfied)
- PhotoMaker Plus: insightface (shared with above)
- Frame-Interpolation: cupy-cuda12x (or cupy)
