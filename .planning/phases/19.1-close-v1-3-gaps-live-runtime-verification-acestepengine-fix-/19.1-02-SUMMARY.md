## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] httpx.ASGITransport does not emit ASGI lifespan events**
- **Found during:** Task 1 (initial test run)
- **Issue:** ASGITransport (httpx 0.28) does not trigger FastAPI lifespan startup/shutdown, so no engines were registered and /health reported 0 engines
- **Fix:** Manually entered lifespan context in fixture via `async with lifespan(app):` wrapper
- **Files modified:** docker/gold-team/tests/test_live_smoke.py
- **Verification:** /health now reports engines.total >= 1, /api/v1/engines lists mock engine

**2. [Rule 3 - Blocking] asyncio Queue bound to wrong event loop in teardown**
- **Found during:** Task 1 (second test run)
- **Issue:** pytest-asyncio creates a new event loop per test (function scope), but module-level singletons (TaskStore, Executor) hold asyncio.Queue instances bound to the prior loop, causing RuntimeError in teardown
- **Fix:** Added `_reset_singletons()` that clears module-level `_store`, `_executor`, `_router`, `_pool` references before each test
- **Files modified:** docker/gold-team/tests/test_live_smoke.py
- **Verification:** All 5 tests pass with clean teardown, no event-loop errors

**3. [Rule 1 - Bug] pytest-asyncio strict mode requires explicit @pytest.mark.asyncio**
- **Found during:** Task 1 (first test run)
- **Issue:** pytest-asyncio 1.3.0 in strict mode does not auto-detect async test methods; tests failed with "async def functions are not natively supported"
- **Fix:** Added `@pytest.mark.asyncio` decorator to all 5 async test methods
- **Files modified:** docker/gold-team/tests/test_live_smoke.py
- **Verification:** Tests are properly recognized and executed as async tests
