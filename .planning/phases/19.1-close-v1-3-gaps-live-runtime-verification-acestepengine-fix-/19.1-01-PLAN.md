<objective>
Fix ACEStepEngine to support dual-mode operation: connect to an external container (kais-acestep) when ACESTEP_API_HOST is non-local, or launch a local subprocess when it is localhost.

Purpose: In Docker deployments (docker-compose.v9.yml), ACESTEP_API_HOST is set to "kais-acestep" (a separate container). The current code always tries to launch a subprocess, which fails because there is no local ACE-Step installation inside the gold-team container. This fix enables the engine to detect external mode and just health-check the remote API.

Output: Modified acestep.py with external-mode detection + new test file verifying both modes.
</objective>
