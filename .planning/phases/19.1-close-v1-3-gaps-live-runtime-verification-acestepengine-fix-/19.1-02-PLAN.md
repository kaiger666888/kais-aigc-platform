    Per D-01 from CONTEXT.md: Create a Python smoke test script using httpx AsyncClient with ASGITransport to test the gold-team API in-process.

    Create docker/gold-team/tests/test_live_smoke.py with a class TestLiveSmoke using pytest-asyncio:

    Test structure:
    - Use a module-level fixture that creates the FastAPI TestClient (httpx.AsyncClient with ASGITransport pointing to "src.v6.main:app")
    - Set environment variables before import to ensure mock-only mode: COMFYUI_ENABLED=false, ACESTEP_API_HOST=127.0.0.1, ACESTEP_ROOT=/nonexistent (so no real engines try to start except mock)
    - Use asyncio event loop fixture for async test methods

    Test methods to implement:

    1. test_health_endpoint: GET /health -> assert status_code == 200, response JSON has keys: "status", "version", "uptime_sec", "engines", "timestamp". Assert "engines.total" >= 1 (at least mock engine).

    2. test_engines_endpoint: GET /api/v1/engines -> assert status_code == 200, response JSON has key "engines" which is a list. Find the mock engine in the list (id="mock"), assert it has "backend_type" key with value "mock". Assert each engine entry has keys: "id", "name", "backend_type", "supported_types", "status".

    3. test_task_submit_and_retrieve: POST /api/v1/tasks with body:
       - task_id: "smoke-test-001" (use uuid to avoid collisions if needed)
       - type: "image_draw"
       - params: {"prompt": "test image"}
       Assert response status_code == 202, response JSON has "task_id", "status" == "queued".
       Then GET /api/v1/tasks/{task_id} -> assert status_code == 200, response JSON has "task_id" matching, "status" field present.

    4. test_task_submit_all_major_types: Loop over TaskType values ["image_draw", "tts", "music", "upscale", "video_final"], submit one task per type, assert each returns 202 with status "queued". This verifies routing coverage for major TaskTypes through the mock engine.

    5. test_duplicate_task_rejection: Submit the same task_id twice, assert second submission returns 400 with error containing "duplicate_task_id".

    Use httpx.AsyncClient with ASGITransport for in-process testing (no Docker required). Import from httpx and use `ASGITransport(app=app)` pattern. The app is imported from src.v6.main.

    Important: The FastAPI lifespan starts engines, so the mock engine will be registered automatically. Other engines may fail to start (no GPU, no ComfyUI) -- that is expected and acceptable. The test only requires the mock engine to be available.

    Add the file to the tests directory alongside the existing test files.
