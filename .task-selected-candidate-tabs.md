# Task: Refactor Asset Library — "选定资产 / 待选资产" two-tab model

## Overview
Replace the current 3-scope system (`全部资产 / 本项目 / 全集资产`) with a cleaner 2-tab model:
- **选定资产** (Selected) — assets with `isPrimaryView=true`. These are what the pipeline uses.
- **待选资产** (Candidate) — assets with `isPrimaryView=false`. Not used by pipeline.

### Rules
1. Default tab: **选定资产**
2. Each `characterId` group (e.g. `shenzhiyi`) should have exactly ONE `isPrimaryView=true` among its variants
3. If a `characterId` group has only 1 variant → it's auto-selected (`isPrimaryView=true`)
4. Switching selection: when user picks a new candidate → old primary in same `characterId` group gets `isPrimaryView=false`, new one gets `isPrimaryView=true`
5. For scenes: same logic but grouped by `characterId` (which stores scene ID like `S01`) instead of actual character ID

// Group assets by characterId to understand "type groups"
// For characters: characterId = "shenzhiyi", "luyanzhou", etc.
// For scenes: characterId = "S01", "S02", etc.
// For other types: each unique name or characterId is its own group

function getGroupKey(d: typeof assets[number]): string {
  // Group by characterId if present, otherwise by type+name
  if (d.characterId) return `${d.type}:${d.characterId}`
  return `${d.type}:${d.name}`
}

const tabFiltered = useMemo(() => {

    return d.isPrimaryView !== true

**Auto-initialize: ensure each group has exactly one primary**
On first load, if any group has no primary, auto-set the first variant as primary:
```typescript
const { assets, loading, error, reload } = useRealAssets(projectId)

// Auto-init: ensure each characterId group has exactly one primary
useEffect(() => {
  if (loading || assets.length === 0) return
  
  // Group by characterId
  const groups = new Map<string, typeof assets>()
  for (const d of assets) {
    const key = getGroupKey(d)
    if (!groups.has(key)) groups.set(key, [])
    groups.get(key)!.push(d)
  }
  
  const needsInit: Array<{id: number}> = []
  for (const [key, group] of groups) {
    const hasPrimary = group.some(d => d.isPrimaryView === true)
    if (!hasPrimary && group.length > 0) {
      // Auto-select first variant
      needsInit.push({ id: group[0].id })
    }
  }
  
  if (needsInit.length > 0) {
    // Fire and forget — just set them
    (async () => {
      for (const { id } of needsInit) {
        try { await updateAsset(id, { isPrimaryView: true }) } catch {}
      }
      await reload()
    })()
  }
}, [assets, loading])  // Run once when assets first load
```

**New handleSelect handler — switch primary within a group:**
```typescript
const handleSelect = async (assetId: number, groupKey: string) => {
  // Find all assets in same group
  const sameGroup = assets.filter(d => getGroupKey(d) === groupKey)
  
  // Unset all primaries in group
  for (const d of sameGroup) {
    if (d.isPrimaryView) {
      try { await updateAsset(d.id, { isPrimaryView: false }) } catch {}
    }
  }
  
  // Set the new one
  try {
    await updateAsset(assetId, { isPrimaryView: true })
    showToast('已设为选定资产', 'success')
    await reload()
  } catch (err) {
    showToast('设置失败: ' + (err as Error).message, 'error')
  }
}
```
