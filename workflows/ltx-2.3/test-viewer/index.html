🎯 msr.ts 现在支持 3 种音频模式
  • dialogue+ambient (默认,v1):SolidMask=0 全段冻结 → bit-exact 拷贝输入音频
  • dialogue+ambient_v2 (partial-mask):对话段冻结 + 环境段模型生成 — 单 pass,弱环境
  • 5stage_pipeline (新增):2 次 LTX pass + ffmpeg ducking — 对话保真 + 丰富环境声
  • 其他:ambient_only / silent / auto
