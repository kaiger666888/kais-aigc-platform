🎯 L8 5 阶段 pipeline vs L7 单次
  • 环境声质量:L8 后段 RMS 0.0096-0.021,L7 是 0.001-0.006,提升 3-16×。Stage 3 不带对话约束,LTX 能把全部注意力放在环境声,peak 0.87(vs L7 的 0.15)
  • 对话保真:Stage 2 直接用 L7 的对话段(sidechain ducking 保证环境声不抢戏),TTS 音色完全保留
  • 代价:多一次 LTX pass(3.5 min),总时长从 3.25 min → 6.85 min。但 Stage 3 的 prompt 不需要多角色参考,理论上可以用更轻量的工作流
  • 可推广:5 阶段 pipeline 适合对话和环境声同时存在的场景(如下雨的同时有人说话)。L7 partial-mask 只能处理时间分段的场景
  • 工程上:所有 Stage 都是独立可缓存可重跑的。Stage 3 失败不影响 Stage 2,Stage 4 调音不满意只需重跑 ffmpeg(秒级)
